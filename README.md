## 📖 About This Project

This repository is part of the **CS50x Persian** initiative, created to make high-quality computer science education accessible to **Persian-speaking learners**.

The project provides Persian-language resources for **Harvard University's CS50 SQL**, helping students learn SQL, relational databases, database design, and practical database development in their native language.

Through **CS50x Persian**, Persian-speaking students can access professionally translated educational content, course materials, exercises, and learning resources designed to make the CS50 SQL curriculum easier to follow and understand.

Our goal is simple:

**To make world-class computer science education accessible to Persian speakers. ❤️**

---

## 🎓 About CS50 SQL

**CS50's Introduction to Databases with SQL** is Harvard University's course covering the fundamentals of databases and SQL.

Throughout the course, students learn how to work with relational databases, write SQL queries, design databases, optimize queries, and solve real-world data problems.

The Persian edition makes these concepts accessible to students who prefer learning technical subjects in Persian.

---

## 📚 What You'll Learn

Throughout CS50 SQL, you will learn:

* Introduction to Databases
* Relational Databases
* SQL Syntax
* Filtering & Sorting Data
* Aggregate Functions
* Joins
* Subqueries
* Database Normalization
* Indexes
* Views
* Transactions
* Data Modeling
* Query Optimization
* Real-world SQL Problem Solving

By the end of the course, you will have a strong foundation in SQL and relational databases and be able to apply these skills to real-world software projects.
